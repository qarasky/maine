# Development

Building, testing and releasing Maine. For using it, see the [user guide](guide.md). Contributor rules for AI agents are in [AGENTS.md](../AGENTS.md).

## Build

Requirements: macOS 14 (Sonoma) or later, Xcode 16 or later selected with `xcode-select` (SwiftUI macros ship with Xcode; Command Line Tools alone are not enough), and the system OpenSSH client at `/usr/bin/ssh`.

```sh
cd apps/macos
scripts/build-app.sh --release --run
scripts/build-app.sh --release --version 1.2.3   # stamp a version into the bundle
scripts/make-dmg.sh 1.2.3                        # build/Maine-1.2.3.dmg + .dmg.sha256
```

The script compiles the package, wraps the binary in `Maine.app` with its `Info.plist` and `AppIcon.icns`, ad-hoc signs it, and with `--run` launches it. The app lands at `apps/macos/build/Maine.app`. A build without `--version` reports `0.0.0-dev`, which never auto-checks for updates.

If `xcode-select -p` prints `/Library/Developer/CommandLineTools`, switch once:

```sh
sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
```

Fast loop:

```sh
cd apps/macos
swift build                         # debug build
scripts/build-app.sh --debug --run
swift run Maine                     # debug executable directly
```

Icon: regenerate the M monogram with `swift scripts/render-mark.swift monogram <master.png>`, then rebuild the `.iconset`/`.icns` with `sips` + `iconutil` as documented in that script's header. `scripts/render-icon.swift` (the `>_` prompt mark) is kept for possible future use.

## Test

```sh
cd apps/macos
swift test                     # everything that does not open a window
MAINE_UI_TESTS=1 swift test    # plus window/layout tests (they take over the screen; CI always runs them)
```

The suite covers the configuration format, host validation, file persistence and permissions, the exact `ssh` command lines, the `~/.ssh/config` reader, the PTY session lifecycle with a real child process, and agent tools, the activity log and the OSC 133 parser.

Other suites:

```sh
(cd packages/schema && python3 tools/validate.py)    # needs only Python 3

cd apps/sync-server
cargo test                                           # unit + HTTP integration
scripts/smoke.sh                                     # whole protocol with curl

cd apps/macos                                        # macOS client against the real server
MAINE_SYNC_SERVER_BIN="$PWD/../sync-server/target/release/maine-sync-server" \
    swift test --filter SyncServerIntegrationTests   # after `cargo build --release` in apps/sync-server

cd apps/android
./gradlew :app:testDebugUnitTest                     # JVM unit tests, no emulator
```

GitHub Actions runs all of this on every push to `main` and every pull request (`.github/workflows/ci.yml`).

## Layout

```
maine/
├── apps/
│   ├── macos/         Swift + SwiftUI application
│   ├── android/       Kotlin + Compose application (vault parity, real terminal)
│   └── sync-server/   Rust sync server (zero-knowledge vault slots)
├── packages/
│   └── schema/        Versioned JSON configuration format + validator
├── docs/              guide, development, architecture, macos-design, mcp, releasing, sync-protocol, sync-client, images
└── README.md
```

Clients share a configuration format, not code: see [`packages/schema/README.md`](../packages/schema/README.md). The encrypted vault envelope is the exception, implemented byte for byte on every client, so a `passwords.maine` copied between machines unlocks with the same master password (proven by `vault-golden-v2.json`, generated by Swift, in the Android tests). The Linux directory is added when that client is built, not before.

More: [architecture.md](architecture.md), [macos-design.md](macos-design.md) (layout references), [mcp.md](mcp.md), [sync-protocol.md](sync-protocol.md), [sync-client.md](sync-client.md).

## Release

Releases are tag-driven: push `vX.Y.Z` and CI tests, builds with `--version` and publishes `Maine-X.Y.Z.dmg` with its `.dmg.sha256`. A hyphen suffix (`v1.2.3-rc.1`) makes a pre-release, which the updater ignores. Steps and the Gatekeeper caveat: [releasing.md](releasing.md).
